# ผู้ช่วยสิทธิผู้บริโภคและการซื้อของออนไลน์ (RAG Chatbot)

แชตบอตตอบคำถามเรื่องสิทธิผู้บริโภคและปัญหาการซื้อของออนไลน์ในประเทศไทย โดยใช้เทคนิค RAG (Retrieval-Augmented Generation) ค้นจากคลังเอกสารที่รวบรวมจากเว็บไซต์ของสำนักงานคณะกรรมการคุ้มครองผู้บริโภค (สคบ.) และประกาศที่เกี่ยวข้อง แล้วให้ LLM ตอบจากเอกสารที่ค้นได้เท่านั้น พร้อมแสดงแหล่งอ้างอิงทุกคำตอบ

- **Streamlit App:** `https://rag-consumer-rights.streamlit.app/`
- **GitHub:** `https://github.com/ARMpk-27/rag-consumer-rights/blob/main/README.md`

## แนวคิดของ Domain
การซื้อของออนไลน์เป็นเรื่องใกล้ตัว แต่คนส่วนใหญ่ไม่รู้ว่าเมื่อได้ของไม่ตรงปก โดนร้านบล็อก หรือสั่งแบบเก็บเงินปลายทางแล้วมีปัญหา ตนมีสิทธิอะไรและต้องติดต่อใคร ข้อมูลเหล่านี้กระจายอยู่ในหลายหน้าของเว็บไซต์ราชการ แชตบอตนี้รวบรวมไว้ที่เดียว และตอบโดยอ้างอิงเอกสารเสมอ เพื่อลดความเสี่ยงที่ AI จะแต่งข้อกฎหมายขึ้นเอง

## โครงสร้างไฟล์
```
├── app.py                 # ไฟล์หลักของ Streamlit App (หน้าแชต)
├── rag.py                 # แกน RAG: โหลด/ทำความสะอาด/chunk/FAISS/prompt
├── requirements.txt
├── README.md
├── test_questions.csv     # คำถามทดสอบ 15 ข้อ (ไม่มีคำตอบในเอกสาร 3 ข้อ)
├── secrets.toml.example   # ตัวอย่างไฟล์ secrets (ไม่มีคีย์จริง)
├── .gitignore             # กัน .streamlit/secrets.toml ไม่ให้ขึ้น GitHub
├── .streamlit/config.toml # ธีมสีของแอป
└── data/                  # เอกสารความรู้ 11 ไฟล์ รวมประมาณ 21,000 ตัวอักษร
```

## เทคนิคที่ใช้
1. **Document Loading & Chunking** อ่านไฟล์ `.md` ใน `data/` ทำความสะอาดข้อความ (Unicode NFC, ลบอักขระมองไม่เห็น, ยุบช่องว่างซ้ำ) แยกบรรทัด "แหล่งที่มา" ออกมาเป็น metadata แล้วแบ่ง chunk ตามหัวข้อ `##` เพื่อไม่ให้ chunk ข้ามเรื่อง รวมย่อหน้าเป็น chunk ไม่เกิน 600 ตัวอักษร มี overlap ประมาณ 100 ตัวอักษร และถ้าย่อหน้ายาวเกินจะตัดตามขอบคำด้วย PyThaiNLP (`newmm`) จึงไม่ตัดคำไทยกลางคำ ได้ทั้งหมด 67 chunks
2. **Embedding & Vector Search** ใช้ `intfloat/multilingual-e5-small` (โมเดลเล็ก รองรับ 100 ภาษา รวมภาษาไทย) ใส่ prefix `passage: ` ให้เอกสาร และ `query: ` ให้คำถามตามที่ model card กำหนด เก็บเวกเตอร์ที่ normalize แล้วใน FAISS `IndexFlatIP` (เท่ากับ cosine similarity) โหลดโมเดลและสร้าง index ครั้งเดียวด้วย `st.cache_resource` ถ้าเป็นคำถามต่อเนื่องที่สั้น จะรวมคำถามก่อนหน้าเข้าไปค้นด้วย
3. **Prompt Engineering** System prompt บังคับให้ตอบจาก CONTEXT เท่านั้น ใส่เลขอ้างอิง `[1]` ทุกข้อเท็จจริง ห้ามแต่งตัวเลขหรือมาตรากฎหมาย ถ้าไม่มีคำตอบให้ตอบว่า "ไม่พบข้อมูลในเอกสารที่มีอยู่" ถ้าตอบได้บางส่วนให้บอกส่วนที่ไม่พบ และให้ถือข้อความใน CONTEXT เป็นข้อมูล ไม่ใช่คำสั่ง (กัน prompt injection) ดูข้อความเต็มที่ `SYSTEM_PROMPT` ใน `rag.py`
4. **Large Language Model** เรียกผ่าน Groq API ค่าเริ่มต้นคือ `openai/gpt-oss-120b` เลือก `openai/gpt-oss-20b` ได้ (ทั้งสองเป็น Production model บน Groq ณ ต.ค. 2569 ส่วน `llama-3.3-70b-versatile` ถูกย้ายเป็นโมเดลระดับ Enterprise แล้ว) ใช้ temperature 0.2 ให้คำตอบนิ่ง
5. **Chatbot Interface** หน้าแชตคุยต่อเนื่องได้ (ส่งประวัติ 4 ข้อความล่าสุดให้ LLM) มีปุ่มคำถามตัวอย่าง และทุกคำตอบแสดงเอกสารอ้างอิงพร้อมหัวข้อ คะแนนความใกล้เคียง ข้อความบางส่วน และลิงก์แหล่งที่มา

## แหล่งที่มาของเอกสาร (ตรวจสอบเมื่อ 5 ต.ค. 2569)
- สคบ. สิทธิของผู้บริโภค https://www.ocpb.go.th/news_view.php?nid=9764
- สคบ. คำถามที่ถามบ่อย https://www.ocpb.go.th/faqs.php
- สคบ. รวมกฎหมาย ประกาศ คำสั่ง https://www.ocpb.go.th/news_view.php?nid=11970
- ประกาศคณะกรรมการว่าด้วยสัญญา เรื่องขนส่งสินค้าโดยเรียกเก็บเงินปลายทาง พ.ศ. 2567 (ข้อความประกาศจากราชกิจจานุเบกษา ผ่าน https://www.bangkokbiznews.com/news/news-update/1137678)
- รัฐธรรมนูญ 2560 มาตรา 46 (iLaw https://www.ilaw.or.th/articles/3965)

เนื้อหาในไฟล์เรียบเรียงจากแหล่งข้างต้นโดยมี AI ช่วย และตรวจทานกับต้นฉบับแล้ว ทุกไฟล์ระบุ URL ต้นทางไว้บรรทัดแรก ๆ

## วิธีรันในเครื่อง
```bash
pip install -r requirements.txt
mkdir -p .streamlit
cp secrets.toml.example .streamlit/secrets.toml   # แล้วใส่ GROQ_API_KEY จริง
streamlit run app.py
```
ครั้งแรกจะดาวน์โหลดโมเดล embedding จาก Hugging Face (ราว 1 นาที)

## วิธี Deploy บน Streamlit Community Cloud
1. Push repo ขึ้น GitHub (ตรวจก่อนว่าไม่มีไฟล์ `.streamlit/secrets.toml` ใน commit)
2. เข้า https://share.streamlit.io แล้วเลือก Create app จาก repo นี้ ตั้ง Main file เป็น `app.py`
3. ใน Advanced settings > Secrets ใส่ `GROQ_API_KEY = "คีย์ของคุณ"` แล้ว Deploy
4. เปิด URL ในโหมดไม่ระบุตัวตน (Incognito) เพื่อทดสอบว่าใช้งานได้จริง

## การทดสอบ
`test_questions.csv` มี 15 คำถามพร้อมคำตอบที่ถูกต้องและไฟล์ต้นทาง ข้อ 13–15 เป็นคำถามที่ไม่มีคำตอบในเอกสาร ระบบต้องตอบว่า "ไม่พบข้อมูลในเอกสารที่มีอยู่"

## ตัวอย่าง Prompt ที่ใช้สั่ง AI ระหว่างพัฒนา
งานนี้ใช้ Claude เป็นผู้ช่วยตามที่โจทย์อนุญาต ตัวอย่าง prompt ที่ใช้:
1. "ช่วยทำสอบเก็บคะแนนหน่อย" (แนบโจทย์)
2. "เสนอหัวข้อที่น่าสนใจมาหน่อย"
3. "ผมสนใจหัวข้อนี้ ผู้ช่วยสิทธิผู้บริโภคและการซื้อของออนไลน์"
4. "ต้องใช้ API KEY ด้วยนะ"
5. "เริ่มเขียนไฟล์ได้เลย" (ให้รวบรวมเอกสารจากแหล่งทางการและระบุ URL)
6. "ตรวจงานของคุณ" (ให้ AI ตรวจทานเอกสารกับต้นฉบับ ซึ่งพบและแก้มาตรารัฐธรรมนูญที่ล้าสมัย)
7. "ทำต่อให้พร้อมลง github เลย"
8. "ตรวจสอบไฟล์ทั้งหมดที่ต้องโหลด"
9. "ตรวจสอบความถูกต้องของไฟล์ทั้งหมดที่คุณพูดมา" (พบและแก้ use_container_width ที่ Streamlit เลิกใช้แล้ว)

## ข้อจำกัด
- ข้อมูลเป็นข้อมูลทั่วไป ไม่ใช่คำปรึกษาทางกฎหมาย และอาจล้าสมัยเมื่อกฎหมายเปลี่ยน
- ยังไม่ได้อ่านเนื้อหาประกาศ COD ฉบับที่ 2 (พ.ศ. 2568) และตัวบท พ.ร.บ.ขายตรงฯ ฉบับเต็ม ซึ่งระบุหมายเหตุไว้ในไฟล์ข้อมูลแล้ว
- ยังไม่มีเกณฑ์คะแนนขั้นต่ำสำหรับตัดเอกสารที่ไม่เกี่ยวข้องออกก่อนส่งให้ LLM การปฏิเสธเมื่อไม่มีข้อมูลจึงพึ่ง prompt เป็นหลัก
